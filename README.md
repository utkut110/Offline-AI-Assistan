# 🤖 Yerel Yapay Zeka Asistanı

Tamamen offline çalışan, Ollama tabanlı terminal yapay zeka asistanı.

## ⚡ Özellikler

* Türkçe terminal arayüzü
* Ollama API desteği
* Otomatik model kontrol sistemi
* Model indirme desteği
* Streaming cevap sistemi
* CMD & Terminal uyumu
* Windows / Linux desteği
* Renkli konsol arayüzü
* Tamamen yerel kullanım

## 📦 Kurulum

### 1. Python yükleyin

### 2. Gereksinimleri kurun

```bash
pip install -r requirements.txt
```

### 3. Ollama kurun

### 4. Model indirip çalıştırın

```bash
ollama run llama3
```

## ▶️ Kullanım

```bash
python ai_asistan.py
```

veya

```bash
calistir.bat
```

## 🧠 Desteklenen Modeller

* Llama 3
* Mistral
* DeepSeek
* Qwen
* Gemma
* Diğer Ollama modelleri

## 🔒 Gizlilik

Tüm veriler cihazınızda kalır, hiçbir bulut sistemi kullanılmaz.

# 🤖 Local AI Assistant

Fully offline terminal-based AI assistant powered by Ollama.

## ⚡ Features

* Turkish terminal interface
* Ollama API support
* Automatic model detection
* Built-in model downloader
* Streaming response output
* CMD & Terminal compatible
* Windows / Linux support
* Colored console interface
* Fully local usage

## 📦 Installation

### 1. Install Python

### 2. Install requirements

```bash
pip install -r requirements.txt
```

### 3. Install Ollama

### 4. Download & run a model

```bash
ollama run llama3
```

## ▶️ Usage

```bash
python ai_asistan.py
```

or

```bash
calistir.bat
```

## 🧠 Supported Models

* Llama 3
* Mistral
* DeepSeek
* Qwen
* Gemma
* Other Ollama models

## 🔒 Privacy

No cloud system is used, all data stays on your device.
